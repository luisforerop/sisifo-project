# Sísifo

Marketplace personal de sub-apps para el día a día (Next.js 16 · React 19 · Tailwind 4).

## Sub-apps

- **Diario del día** (`/diario`): registro diario rápido, historial y exportación JSON.

## Comandos

```bash
npm run dev     # desarrollo en http://localhost:3000
npm run lint
npm run build
```

Los datos se guardan por ahora en `localStorage`. Para agregar una sub-app, ver [`docs/adding-a-subapp.md`](docs/adding-a-subapp.md).
